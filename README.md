# Spotify_Listening_Trends_Dashboard

The Spotify Analysis Power BI Dashboard offers data-driven insights into user streaming behavior by analyzing historical Spotify data. It tracks album, artist, and track engagement over time, identifies listening trends, and compares year-over-year patterns to highlight shifts in music consumption.

Key features include total albums, artists, and tracks played, weekday vs. weekend listening habits, and top-played music rankings. A peak listening hours heatmap visualizes user activity, while a scatter plot analysis categorizes tracks by frequency and duration. Shuffle and skip rate analytics provide insights into engagement and music preferences.

An interactive grid view enables in-depth exploration, featuring drill-through navigation and CSV export for further analysis. The dataset includes track metadata, timestamps, device types, and user actions. Built with Power BI and DAX.

This Spotify analytics dashboard helps users and streaming platforms optimize engagement by uncovering music trends and listening behaviors efficiently.
